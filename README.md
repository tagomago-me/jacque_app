# Jacque (iPhone + Apple Watch)

App do agente de treino Jacque. O Watch lê o bpm durante o treino, o iPhone envia ao gateway Tago-OS, que grava junto com os exercícios.

Setup: copie `JacqueTreino/Secrets.swift.example` para `JacqueTreino/Secrets.swift` e preencha. O token vive nos segredos do gateway, nunca no git.
